============================================
VERSION 5 - Version Finale Complete
============================================

DESCRIPTION :
Version finale avec toutes les fonctionnalites
des versions precedentes plus des ameliorations
avancees.

FONCTIONNALITES DE BASE :
- Connexion TCP multi-clients (max 20)
- Identification avec pseudo
- Broadcast, unicast, multicast
- Salons avec mot de passe optionnel

AMELIORATIONS :
- Transfert de fichiers avec approbation
- Expulsion avec /kick
- Message d'absence avec /away
- Statistiques avec /stats
- Horodatage des messages [HH:MM:SS]
- Logs dans chat.log
- Notifications en temps reel
- Thread POSIX pour reception asynchrone
- Gestion propre de Ctrl+C

COMPILATION :
    make

UTILISATION :
    Terminal 1 : ./server
    Terminal 2 : ./client 8080 127.0.0.1

COMMANDES :
    /nick <pseudo>              : Choisir son pseudo
    /who                        : Liste des connectes
    /whois <pseudo>             : Infos utilisateur
    /msg <pseudo> <message>     : Message prive
    /create <salon> [mdp]       : Creer un salon
    /join <salon> [mdp]         : Rejoindre un salon
    /leave                      : Quitter le salon
    /list                       : Liste des salons
    /msgsalon <message>         : Message dans salon
    /kick <pseudo>              : Expulser un utilisateur
    /away [message]             : Message d'absence
    /stats                      : Statistiques serveur
    /sendfile <pseudo> <fich>   : Envoyer un fichier
    /accept                     : Accepter un fichier
    /reject                     : Refuser un fichier
    /help                       : Afficher l'aide
    /quit                       : Se deconnecter

FICHIERS :
    server.c   : Code source du serveur
    client.c   : Code source du client
    Makefile   : Script de compilation
    chat.log   : Journal des activites
